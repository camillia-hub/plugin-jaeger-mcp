# Jaeger MCP

Reads Jaeger traces. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/jaeger-mcp

Installs from the Camillia hub as `jaeger-mcp-b569fd`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
